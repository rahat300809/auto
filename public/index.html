Setup & Firebase Deployment Guide

1

Generate a GitHub Personal Access Token

Go to GitHub Settings → Personal Access Tokens (Classic).

Check the repo scope and the workflow scope, then click Generate token and paste it into the dashboard.

2

1-Click 24/7 Cloud Automation

Click the "Install 24/7 Cloud Automation" button. The website uses the GitHub API to directly create the .github/workflows/auto-push.yml file in your repository.

Once created, GitHub runs the automated push twice daily at 12:00 AM and 12:00 PM without you ever touching it!

3

Deploy This Website to Firebase Hosting

To host this website on your free Firebase account:

# 1. Login to Firebase
firebase login

# 2. Deploy the site to Firebase Hosting
firebase deploy --only hosting
